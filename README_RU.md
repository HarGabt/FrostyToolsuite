# FORK NOTE

Данный форк Frosty Tool Suite 1.0.7 сделан на основе [форка от selphea, который так же задумывался для долгосрочной поддержки NFS Unbound](https://github.com/selphea/FrostyToolsuite). Задача данного форка — привнести часть функционала из версии 1.0.6.3, и, при возможности, из других форков 1.0.7 (например, [форк от J-Lyt для Dragon Age: The Veilguard](https://github.com/J-Lyt/FrostyToolsuite), при этом поддерживая файл SDK для NFS Unbound в обновлённом состоянии. Данная версия предоставляет собой возможность чтения и модификации ресурсов более новых игр на движке Frostbite, которые не поддерживаются версией Frosty 1.0.6.3. После выхода Frosty Tool Suite 2.0 (срок релиза неизвестен) поддержка данной версии будет прекращена.
<br> Коммиты-бэкпорты в данной репозитории носят характер "а что если", "пусть тут будет, авось скомпилится и не вызовет ошибок", и вы имеете полное право относиться к этому с максимальным скептизмом. Так что прошу вас докладывать обо всех багах, если они найдутся. Известные баги вы можете найти в разделе [Known Issues](https://github.com/HarGabt/FrostyToolsuite/issues/19). Если во время работы с этой версией у вас возникнут ошибки и/или вылеты, оформляйте Issue, и я попробую разобраться с этим. Но учтите, что [изначальные разработчики Frosty 1.0.7 прекратили разработку и не предоставляют какой-либо поддержки по этой версии](https://images2.imgbox.com/a6/a1/CqTQvcGL_o.png), что означает, что если у вас что-то пойдёт не так и я не смогу вам помочь в этом, вы будете сами по себе с вашей проблемой.

## Чем этот вариант отличается от всех существующих вариаций 1.0.7 и что в нём нового?

- Поддержка моддинга InitFS (поддержаны NFS Heat и NFS Unbound)
- Улучшено импортирование 3D-моделей:
  - Поддержано импортирование моделей для игр с поддержкой касательного пространства (Tangent space compression) (для NFS Heat и NFS Unbound)
  - Более детализированные ошибки при импортировании модели
- Поддержан моддинг ассетов типа Template и Blueprint (моддинг ресурсов вида RimeWidgetBlueprint на данный момент поломан. Исправил бы, если бы знал, как)
- Исправлено закрытие из Mod Manager: вам больше не придётся вручную закрывать его в Диспетчере задач, и он не будет висеть в памяти, занимая лишний гигабайт(ы).
- Поддержано создание символической ссылки на папку `shadercache`: должно помочь с производительностью игр на DirectX 12 при запуске игр с модами
- Исправлен вылет при запуске программы с ошибкой `Ссылка на объект не указывает на экземпляр объекта` и `IterateSubKeys`
- Расширенный функционал фильтра в Mod Manager: теперь вы можете включить отображение только включённых или не добавленных модов в разделе  `Available Mod(s)`
- Исправлен вылет с ошибкой на файл `ealayer3.dll` при открытии аудиоконтейнеров. Тем не менее, некоторые из ассетов типа `NewWaveAsset` всё же вызывают вылет из-за уникальной структуры.
- Добавлены плагины, расширяющие функционал редактора
- Mod Manager больше не идентифицирует себя как Editor
- Исправлено отсутствие игрового баннера во время загрузки профиля
- Mod Manager теперь показывает, для какой версии игры (Volume) был сделан тот или иной мод

## Что планируется и/или над чем идёт работа

- Полноценная поддержка Battlefield 6
- Поддержка Skate.™️
- Поддержка Dead Space (моддинг должен уже работать, но игра не подхватывает изменённые файлы)

- Поддержка импорта аудио в ассетах `NewWaveAsset` (импортер на данный момент нерабочий)

# FrostyToolsuite
The most advanced modding platform for games running on DICE's Frostbite game engine.

## Setup

1. Download the source code.
2. Open the solution (found under FrostyEditor) with Visual Studio 2022, and make sure the project is set to ``Release - Final`` and ``x64``. Close out of retarget window if prompted.
3. Only build the projects themselves, never the solution.
